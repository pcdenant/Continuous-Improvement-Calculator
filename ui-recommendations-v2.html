Philosophy

Financial instrument controls feel precision-machined. Hard edges, monospace labels. Tabs replace 4 stacked repetitive cards — one dimension at a time.

Key Changes

  • All buttons: 0px radius, monospace ALL CAPS
  • Secondary + danger: border-only (consistent pair)
  • No translateY lift anywhere
  • Breakdown: 4 tabs instead of 4 stacked cards
  • Active tab = yellow underline, not background fill
  • No nested cards anywhere

Philosophy

Buttons that reveal information shouldn't look like primary CTAs. Minimize the button surface area — let the data lead, not the chrome.

Key Changes

  • "Show Breakdown" → inline disclosure row (▼ text, no button box)
  • "Save/Share" → icon button in the section header
  • "Clear Data" → two-step confirm (try clicking it)
  • Zero standalone action-button row
  • Breakdown: 2×2 grid instead of 4 stacked cards
  • Formula collapsed per-quadrant by default
