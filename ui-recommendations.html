Design Critique — Impeccable Framework

3 UI Improvement Proposals
for the CI Calculator

Each version targets a different layer of the current design — from surface typography to structural hierarchy to executive visual presence.

✦ Principles from github.com/pbakaus/impeccable — design guidance for AI coding agents
✦
No Overused Fonts
"Don't use overused fonts (Arial, Inter, system defaults)" — the current app uses Inter everywhere.
◈
Tint Your Grays
"Don't use pure black/gray — always tint." Current grays (#4a4a4a, #7a7a7a) are brand-neutral.
▣
No Nested Cards
"Don't wrap everything in cards or nest cards inside cards." Summary has 4 glass cards inside a green card.
▲
Hierarchy Drives Clarity
The most important number must look most important. Financial impact values are 2rem — same weight as labels.

What changes in V1
A
Font: Inter → Plus Jakarta Sans
More geometric and warm. Less associated with the mass of 2020-era SaaS dashboards.
Impeccable: "Don't use overused fonts (Arial, Inter, system defaults)"
B
Gray text: pure → brand-tinted
#4a4a4a → #3d4a41 · #7a7a7a → #5a7060. A subtle green cast ties neutrals to the brand instead of reading as default gray.
Impeccable: "Don't use pure black/gray — always tint"
C
Card radius: 20px → 6px
20px is the canonical "friendly SaaS" radius from 2020. 6px reads as more precise — better fit for a financial tool.
Impeccable: Avoid AI-generated design tells
D
Section titles: add bottom border rule
A 1px line under each section title creates a visible content boundary, replacing implicit visual grouping with structural clarity.
Impeccable: /impeccable layout — spacing and visual rhythm
E
Input fields: radius 12px → 4px
Consistent with the card radius change. More "instrument panel" than "mobile form input."
Impeccable: Internal consistency
F
Input background: cream → tinted green-white
#FBF3EB → #f2f6f3. Keeps the warm feel but ties input backgrounds to the green system, not a generic warm cream.
Impeccable: "Don't use pure black/gray — always tint"

What changes in V2
A
Remove 4 nested glass cards in summary
rgba(255,255,255,0.1) cards inside a green card = three levels of visual framing with no hierarchy benefit. Replaced by flat column layout with hairline dividers.
Impeccable: "Don't wrap everything in cards or nest cards inside cards"
B
Dimension values: 1.1rem → 1.5rem
Flat layout gives each value more breathing room. Numbers are what the user is reading — they should dominate over the label.
Impeccable: Hierarchy drives clarity
C
Total impact: 1.35rem → 2.5rem + yellow color
This is the number the CFO wants. It must be unambiguously the largest element in the section. Yellow is already the accent — use it semantically for the hero number.
Impeccable: The most important number must look most important
D
Annual projection: visible alongside the total
+$394K/year is often more compelling for a CFO than $98K/period. It should appear directly under the total, not as a muted caption on each dimension card.
Impeccable: /impeccable clarify — improve what matters
Version 3
Executive Authority — Full Visual Redesign
The audience is CFOs and directors. The design should signal "financial instrument," not "SaaS dashboard." Bold structural changes to header and summary. Cumulative — includes all V1 + V2 improvements.

What changes in V3 (cumulative — builds on V1 + V2)
A
Header: cream background → full dark green band
The brand color is green. The header shouldn't use the same cream as the body. A #004d32 header immediately communicates authority and anchors the brand above the fold.
Impeccable: /impeccable bolder — amplify understated designs
B
Title color: green on cream → yellow on dark green
Yellow (#FFF200) is the existing accent color. On deep green it creates an executive-grade contrast that's distinctly brand-specific, not a generic SaaS palette.
Impeccable: Strategic color — one signal, one meaning
C
Total impact: moved to centered hero position
The CFO opens this page to see one number. Put it first, make it largest, give it yellow. Everything else — dimensions, period, annual — is supporting detail.
Impeccable: The most important thing must look most important
D
4 dimensions: nested cards → left-border accent rows
A 3px yellow hairline gives each dimension a visual anchor without creating card-in-card nesting. Compact, instrument-like, scannable in under 2 seconds.
Impeccable: "Don't nest cards inside cards"
E
Summary background: diagonal gradient → flat #004d32
A CSS gradient diagonal is a minor AI-design tell. Flat deep green reads as more deliberate and premium — the gradient added no information.
Impeccable: Avoid AI-generated design tells (purple gradients etc.)
F
Annual projection: co-located with total hero
+$394K/year is often more compelling than $98K/period for a CFO. It appears immediately below the hero number, not buried as a small caption in each dimension card.
Impeccable: /impeccable clarify

How to Implement

V1 — CSS only · ~30 min
Add Plus Jakarta Sans to the Google Fonts import. In :root: change --text-secondary to #3d4a41, --text-muted to #5a7060, --border to #c5d5c9. On .bento-item: border-radius: 6px. On input[type="number"]: border-radius: 4px. On .section-title: add border-bottom: 1px solid var(--border); padding-bottom: .625rem. Zero HTML changes.
V2 — HTML + CSS · ~2h
Remove the 4 .summary-item divs and replace with flat column cells (no background, no border-radius). Increase .summary-value font-size to 1.5rem. Restructure the .total-line block: move the value above the annual projection, set font-size: 2.5rem and color: var(--yellow). Update the 4 DOM references in calculate() to match new IDs if renamed.
V3 — Full redesign · ~4–6h
Add background: #004d32 to header, set h1 color: var(--yellow), subtitle color: rgba(255,255,255,.65). In .summary: change to background: #004d32 (no gradient). Add a .total-hero block with text-align center above the 4 dimensions. Replace .summary-item with .dim-row elements styled with border-left: 3px solid var(--yellow). Apply all V1 + V2 changes.
